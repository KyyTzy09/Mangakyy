# H18 Mode (Mode Dewasa Terisolasi) Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Menambahkan Mode H18 (`/h18`) ke MangaKyy dengan struktur UI identik dengan mode reguler namun bertema solid pink, diproteksi dengan Route Guard ketat berbasis autentikasi Passcode 11-digit (tersimpan di cookie 30 hari), dan integrasi API nhentai-api di server Nitro.

**Architecture:** 
- Route layout terisolasi di `/h18` dengan `beforeLoad` Route Guard yang memvalidasi cookie sesi `mangakyy_h18_session`.
- Verifikasi Passcode 11-digit dijalankan di Server Function (`createServerFn`) membandingkan input dengan `process.env.H18_PASSCODE`.
- Service server-side `H18Service` membungkus `nhentai-api` dengan dukungan custom agent/proxy dan Cloudflare clearance cookie.
- Theming solid pink (`--color-h18: #ff2d78`) diterapkan pada komponen UI yang mengadopsi struktur identik mode normal (Carousel, Cards, Detail, Reader).

**Tech Stack:** TanStack Router, TanStack Start (Nitro SSR), nhentai-api, Zod, Tailwind CSS v4, Motion (Framer Motion).
